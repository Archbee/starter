Static files like images, logos, and favicons live **inside your docs folder**
(your `docsPath`, e.g. `guides/`). A leading `/` in an image path is resolved
relative to `docsPath` — not the repository root — so the same paths work both
in local preview and on the published Archbee site.

## Adding Images

Place an image under your docs folder, e.g. in an `assets/` directory:

```
my-docs/
  guides/            ← docsPath
    assets/
      screenshot.png
    index.mdx
```

Reference it in your MDX with a path relative to `docsPath`:

```markdown
![Screenshot](/assets/screenshot.png)
```

You can also use a path relative to the current doc:

```markdown
![Screenshot](assets/screenshot.png)
```

## Logos

Configure light and dark logos in `archbee.json` (paths relative to `docsPath`):

```json
"logos": {
  "light": "/assets/logo-light.png",
  "dark": "/assets/logo-dark.png",
  "favicon": "/assets/favicon.ico"
}
```

The light logo appears in light mode, the dark logo in dark mode. If only one is provided, it's used for both.

### Supported Formats

- **Logo:** PNG, SVG, JPG, WebP (recommended: SVG or PNG with transparency)
- **Favicon:** ICO, SVG, PNG

### Recommended Sizes

| Asset | Size |
|-------|------|
| Logo | 200px wide, any height |
| Favicon | 32x32 or 192x192 |

## File Organization

Keep your assets organized under `docsPath`:

```
guides/            ← docsPath
  assets/
    logo-light.png
    logo-dark.png
    favicon.ico
    images/
      hero.png
      diagram.svg
    downloads/
      guide.pdf
```

Reference nested files with the full path (relative to `docsPath`):

```markdown
![Hero](/assets/images/hero.png)
```

## External Images

You can also use external image URLs:

```markdown
![Alt text](https://example.com/image.png)
```

External images are not served by the dev server — they require an internet connection.
