Inline links use standard Markdown syntax. Archbee resolves doc paths automatically — see [Links](/essentials/links) for the resolution rules.

Read the [Quickstart](/quickstart) to get started, or visit [archbee.com](https://archbee.com) for more.

## Syntax

```markdown
[Quickstart](/quickstart)
[archbee.com](https://archbee.com)
[Email us](mailto:support@archbee.com)
```
